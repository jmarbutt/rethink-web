# Domain Docs

This repo uses a single-context domain-doc layout.

Before exploring, engineering skills should read:

- `CONTEXT.md` at the repo root, if it exists
- `docs/adr/`, if it exists, for architectural decisions relevant to the task
- The task-specific docs already named in `AGENTS.md`

If `CONTEXT.md` or `docs/adr/` does not exist, proceed silently. Do not request creating them upfront.

When output names a domain concept, use the vocabulary from `CONTEXT.md` when available. If a change contradicts an ADR, call out the conflict explicitly.
